# Traps

The evidence behind `CLAUDE.md`'s Traps section: the measurements, captures, versions and
numbers that prove each conclusion. Every file here is pointed at by an index line in
[`CLAUDE.md`](../../CLAUDE.md), which is where you find the one that guards the file you
are about to edit — start there, not here.

These are maintainer-facing, unlike [`docs/panel.md`](../panel.md) and
[`docs/team.md`](../team.md): they assume you are editing this code, not running it.
